# Тема дня

Крутишь рулетку — выпадает случайная тема: 20 минут разбираешься, потом записываешь минутное видео, где объясняешь её своими словами. Сколько тем в день — решаешь сам. Пройденные темы складываются в галерею-пузыри.

## Установка на телефон

1. Открой ссылку на приложение в Safari (iPhone) или Chrome (Android).
2. iPhone: «Поделиться» → «На экран „Домой“». Android: меню → «Установить приложение».

Всё хранится только на твоём устройстве: прогресс, заметки, видео, фото. Регистрации нет.

## Свои темы

Настройки → Темы — добавить, переименовать, удалить.
Настройки → Импорт — `.txt` в формате:

```
# 🧪 Область | #9CC5A1
## Раздел
Тема
Ещё тема
```

## Запуск локально

```
python -m http.server 8000
```

Открыть http://localhost:8000. Камере нужен https или localhost.
